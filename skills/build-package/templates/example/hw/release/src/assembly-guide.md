# Assembly guide · Fixture board rev A (test fixture)

Build size: 10 units. Time per unit: 6 min [estimate: fixture].

## Steps

### 1. Insert the cell

1. Slide the CR2032 into J1 with the positive face up.

- **Adhesive / cure:** none
- **Torque:** none
- **QC:** VBAT at TP1 = 3.0 V ± 0.2 V.

### 2. Close the shell

1. Place the board in the shell, cell side down.
2. Press the lid until it clicks.

- **Adhesive / cure:** none
- **Torque:** none
- **QC:** the lid is flush: step ≤ 0.1 mm at 4 points.
