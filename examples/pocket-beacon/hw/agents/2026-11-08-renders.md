## Toolkit bugs found
- TB-R1: `studio.py` hides every light it did not create, so a shot-level LED point light is silently dropped. Workaround: an emissive bead invisible to camera/transmission/glossy. Fix: let `studio.py` keep lights tagged `hdt_keep_light`.
- TB-R2: KiCad GLB component empties carry a 1000× scale; offsets in an empty's local frame must use rotation only (`matrix_world.to_quaternion()`), or they land metres away.
- TB-R3: `studio.py --target` with a glob that matches only empties fails ("no renderable objects"); a lineup must target a collection.
- TB-R4: `materials.py plastic_white`/TPU over a dark cavity reads dark when subsurface scale is large; membranes need a small SSS scale unless lit from inside.
