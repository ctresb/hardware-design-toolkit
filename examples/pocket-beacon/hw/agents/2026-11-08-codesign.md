## Toolkit bugs (found by running the toolkit on a real design)

| # | Skill / script | Bug | Workaround in this project |
|---|---|---|---|
| TB-1 | enclosure-engineer `cad_enclosure.py` | `twist` joint only for a circular outline; a rounded-square body with a round door cannot be built | project script `hw/mech/cad_pocket_beacon.py` that reuses `dfm_check` and `write_reports` |
| TB-2 | enclosure-engineer `cad_enclosure.keepout_check` | crashes (`'NoneType' object has no attribute 'volume'`) when a keep-out does not touch a part: build123d returns `None` for an empty intersection | safe copy in the project script |
| TB-3 | pcb-engineer `outline.py` `union` | `fillet` rounds only `rect` corners and joins, not `polygon` corners; the spec doc says "rounds every corner" | outline written as an explicit polygon with arcs |
| TB-4 | pcb-engineer `pcbgen.py` legalizer | uses the courtyard **bounding box**: a round coin-cell holder blocks the whole 23.7 × 21 mm rectangle and its corners collide with an outline chamfer | holder offset to (−1.1, −1.1); test points moved to bands outside the box |
| TB-5 | pcb-engineer `route.py` | runs Java on the local machine; no split DSN export / SES import for the documented "route on another machine" step | project script `hw/pcb/route_remote.py` |
| TB-6 | pcb-engineer `route.py` (KiCad 10.0.8) | zone restore: `ZONE.Outline()` returns an unwrapped SwigPyObject (`NewOutline` AttributeError); `board.GetTracks()` flaky after save | build a `SHAPE_POLY_SET`, then `zone.SetOutline()`; no track count |
| TB-7 | toolchain-setup / pcb-engineer docs | Freerouting 2.5.0 needs **Java 25** (class file 69); docs say Java 21+ | Temurin 25 on the cloud VM |
| TB-8 | pcb-engineer workflow | Freerouting 2.5.0 stops after ~19 passes when the score stops improving (no CLI switch); dense small boards stay partially routed | see the routing log in the retro |
| TB-9 | pcb-engineer `pins.py` | traceback instead of a message for an unknown symbol | none needed |
