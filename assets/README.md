# Brand assets

| File | Use |
|---|---|
| `logo.svg` / `logo.png` | Lockup for light backgrounds |
| `logo-dark.svg` | Lockup for dark backgrounds |
| `logo-mark.svg` / `logo-mark.png` | Square mark (app icon, favicon, avatar); legible down to 16 px |
| `banner.svg` / `banner.png` | 1280 × 640 README and social preview image |

The mark is a length-tuned PCB trace (a serpentine meander) between two vias. It reads as a routed trace and as a sound wave. The right-hand via carries the only accent color.

| Token | Hex |
|---|---|
| Ink | `#15171A` |
| Paper | `#F7F6F2` |
| Accent (signal orange) | `#FF6A13` |
| Grey (light bg) | `#6B6F76` |
| Grey (dark bg) | `#A3A7AD` |

The wordmark is converted to outlines from [Inter](https://rsms.me/inter/) (SIL Open Font License 1.1). The SVGs therefore need no font installed.
